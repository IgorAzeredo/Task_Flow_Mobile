# 📝 TaskFlow Mobile

Aplicativo mobile de gerenciamento de tarefas desenvolvido com React Native, Expo e TypeScript.

## 🚀 Tecnologias utilizadas

- React Native
- Expo
- Expo Router
- TypeScript
- JavaScript
- Git e GitHub

## 📋 Funcionalidades

- Adicionar tarefas
- Validar tarefas vazias
- Listar tarefas
- Marcar tarefas como concluídas
- Desmarcar tarefas concluídas
- Excluir tarefas
- Componente reutilizável para cada tarefa
